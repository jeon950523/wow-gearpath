## 최상위 단계와 우선순위
[공통 제품 로드맵](PRODUCT-ROADMAP.md)이 단계 진입/범위 결정의 기준이다. 핵심 수집과 웹 MVP를 병렬 완성하고 사용자 승인 후 경량 PC 앱, 로컬 심크, 종합 최적화로 진행한다. 아래 기존 TASK/SIM 식별자와 이력은 유지하며 SIM-001/002 준비는 핵심 MVP를 지연시키지 않는 범위로 제한한다.

신규 기능 구현 전 [공통 외부 애드온 활용 정책](research/ADDON-INTEGRATION-POLICY.md)과 후보별 적용 우선순위를 확인한다. 기존 로드맵 순서를 유지하고 수집·분석 계약을 선합의한다.

1. TASK-002. 한국 리테일 장비 조회 및 웹 진단.
2. TASK-003. 공통 계약, 애드온 데이터 가져오기와 출처 병합.
   - TASK-003A / CONTRACT-001. 상세 수집 호환, 직접 교차 검증, 수동 CI 및 main 운영 배포 정책 적용.
3. TASK-004. 시즌 팩과 검증 모듈, ADDON-003A 교차 검증과 003B 계약을 추가했습니다. 남은 작업은 게임 화면으로 일반 강화·구렁·금고의 수치와 신규 화폐의 범위 및 상인 교환표를 검증하는 것입니다.
4. TASK-005 성장 최적화. 슬롯별 강화 단계와 비용, 목표, 재화 보존 및 교체 근거를 모델링했습니다. 국내 실측 데이터로 운영 규칙을 채우고 일일·주간 활동 및 대체 장비 획득 규칙을 후속 검증합니다.
5. 골드 획득과 전투부대·부캐 관리, 계정 동기화는 수집 범위와 저장 모델을 별도 검토합니다.

## 시즌 데이터 구조 초안

확장팩 → 시즌 → 패치 적용 구간을 ID로 연결합니다. 구간마다 콘텐츠, 난이도, 보상 규칙, 상인 교환, 재화, 전리품 목록을 참조합니다. 보상에는 아이템/슬롯, 트랙, 레벨 범위, 획득 조건, 잠금/주간 제한, 재화 비용, 확률을 기록합니다. 각 행에 지역, 적용 시작·종료, 확인일, 출처, 검증 상태, 이용 허용 범위를 둡니다. 누락된 획득률과 미검증 가격은 계산을 보류합니다.

공식 공지와 게임 화면을 우선합니다. 커뮤니티 자료는 시즌과 검증일을 행별로 대조한 뒤 참고합니다.

## 심크 통합 로드맵 (승인된 후속 범위)

### 웹 책임 및 단계
- SIM-001: 기존 /simc 프로필 텍스트 입력/검증, GearPath JSON 및 API와 안전하게 매칭. 지원하는 SimC 입력 문법의 범위를 정의하고 알 수 없는 지시문은 실행하지 않는다.
- SIM-002: 사용자가 내보낸 실제 SimC/Raidbots 결과의 지원 형식·비교 UI, 기준 DPS 대비 차이·불확실성·장비 레벨을 함께 표시. 외부 서비스 결과 접근/이용 조건 검증 전 자동 연동 금지.
- SIM-003: 사용자 PC의 버전 고정 SimC 실행 연동 검토. 별도 로컬 실행 모듈, 안전한 입력, 취소/시간 제한 및 결과 검증. 서비스 서버의 자동 실행은 승인 범위 외.
- SIM-004: Quick Sim, Top Gear, Droptimizer, Upgrade Sim, 특성·장신구·티어·보석/마법부여 비교. 후보 선별, 조합 상한, 캐시 키(버전/패치/프로필/시나리오), 통계 오차 비교를 먼저 설계한다.
- TASK-009 이후 통합: 실제 시뮬레이션 결과를 재화 기회비용·획득 가능성·시간·주간 제한과 결합한다. 미검증 보상 규칙이나 가상의 DPS를 실제 추천 근거로 사용하지 않는다.
- 현재 TASK-004 시즌/재화 계약과 ADDON-003A 검증을 우선 유지한다. SIM-001/002는 장비/강화 엔진 기반 확보 후, SIM-003/004는 별도 단계로 진행한다. 이 변경은 계획/문서만이며 계약의 실제 신규 필드, 런타임, 배포 기능 및 엔진은 아직 구현하지 않는다.
