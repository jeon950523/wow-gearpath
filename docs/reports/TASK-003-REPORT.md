# TASK-003 검수

기존 웹은 공식 API 조회와 수동 입력을 지원했지만 애드온 JSON을 웹에서 가져올 수 없었습니다. 사용자 확인에 따르면 TASK-002 운영 환경의 실제 장비는 게임과 대조를 완료했습니다. 이는 자동 검증과 별도입니다.

애드온 main의 SSOT, HANDOFF, README, v0.1.1 예제 2종을 대조했습니다. 애드온은 장착 아이템 레벨·무기 유형·캐릭터 골드를 수집합니다. 강화 단계, 문장 등 주요 재화, 구렁·금고 상태, 쐐기돌은 이 버전에서 미수집입니다. 웹 회귀 검사는 애드온 쪽 Lua 실행 및 0.1.1 인게임 QA와 별개입니다.

기능 개선은 입력 크기·버전·장비·캐릭터·시즌·시각 검증, 수집 상태, 원본 출처와 삭제입니다. 효율 개선은 브라우저 내부의 단일 파싱과 필드 허용 목록, 장비 세트 단위 병합, 스냅샷 미전송입니다. 장비 충돌 시 출처를 직접 선택할 수 있습니다. 재화는 알려진 값을 우선하고 같은 종류의 관측값 중 최신값을 선택합니다. 사용자가 확인해 직접 입력한 수치는 적용된 동안 우선합니다.

웹 계약 자동 검사는 사냥꾼 308.6875, 315 및 솔플 옵션, 오래된 자료, 동명 구분, 수동 0과 null, 반복 가져오기, 민감한 확장 제외를 검사합니다. 실사용자의 0.1.1 내보내기 결과는 별도 인게임 검증 대상으로 남습니다.
