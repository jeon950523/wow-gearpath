## 작업
1. 애드온 tests/addon-load.test.lua의 합성 운영 JSON 생성 경로와 원본 SHA를 확인하고 가능한 경우 실행하여 테스트 fixture를 만든다. 실제 사용자 JSON은 사용자 동의 하에 로컬/브라우저에서만 전달·검증한다. 개인 식별자·잔액·원문을 GitHub, 로그, 서버, 배포 번들에 저장 금지. 재구성 fixture는 합성/익명화로 표기하고 실제 원본 검증으로 주장하지 않는다. 사용자 원본 접근 불가 시 별도 차단으로 남긴다.
2. 실제 웹 Ajv 2020-12 전체 v1 → parseAddon → mergeSnapshots → validate/diagnose → 통합 대시보드/브라우저에서 신규 생성 JSON과 기존 v0.3.2, v0.2.1, 기본 export를 검증. 웹/애드온 문서에 기록된 정확한 SHA 및 소스/관측 시각 기록.
3. 최신 실제 인게임 JSON은 실제 관측 시각을 now로 주입한 결정적 테스트와 현재 실제 시각의 브라우저 검증을 구분한다. 15분 TTL이 지난 자료는 역사/참고로 표시해야 정상이다. 갱신 필요 시 새 export를 요청하여 실제 활성·만료·추천 화면 확인. 테스트 편의를 위해 원본 timestamp를 바꾸거나 운영 TTL을 완화하지 않는다.
4. 동일 시점 관측 지도/퀘스트/보상 그룹/만료/장비 평균 및 0/null 보존, 72개 그룹 시각, 만료 미확인 행 제외, 골드 단위 표시·보유량/성장 예산 분리, 선택/캐시 미합산, 부분 관측 상태, 오래된 스캔/이전 기본 export/동시각 충돌/전문화·캐릭터 변경, 3418 및 315/솔플 회귀, 입력 256 KiB 검증. 실제 관측 결과는 보고서의 요약과 비교하며 보상 획득/툴팁 정확성은 별도 실제 UI 승인으로 구분.
