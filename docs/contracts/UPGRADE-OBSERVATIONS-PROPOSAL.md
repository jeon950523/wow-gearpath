# 강화 관측 계약 제안

이 문서는 사전 협의용입니다. snapshot-v1과 ADDON-003B 계약은 그대로 유지합니다.

## 한국 클라이언트 확인 요청

| 항목 | 익명 관측에 필요한 값 |
| --- | --- |
| 일반 강화 | 지역, 게임 패치·빌드, 시즌, 관측 시각, 장비 링크의 비개인화된 인스턴스 정보, 슬롯, 트랙, 현재 단계/레벨과 다음 단계/레벨 |
| 가격 | 적용 전후 문장 종류와 수량, 골드, 실제 UI의 할인 설명 및 자격 조건. 할인 없음도 명시합니다. |
| 할인 | 캐릭터 및 전투부대 각각의 슬롯 최고 획득 레벨, 해당 값의 관측/미확인 상태. 반지, 장신구, 양손, 원거리, 쌍수, 한손+방패를 각각 비교합니다. |
| 최대 단계·특수 강화 | 최대 단계 표시, 맹독석 사용 전후 레벨, 적용 횟수/재적용 가능 여부, 장식·제작 품질·재제작과의 상호작용, 시즌/획득 유형별 예외 |
| 교체 후보 | 명시적으로 수집한 가방/은행 범위, 인스턴스 식별, 장비 제한과 세트/장식/효과, 보상 출처 및 확인된 시각 |

장비 링크·bonusIds·setId와 슬롯은 웹에서 보존하지만 영구 장비 인스턴스 식별자로 취급하지 않습니다. 계정이나 캐릭터를 식별할 수 있는 값은 익명화합니다. 각 값은 같은 장비 스냅샷에 대응시켜야 하며 null과 실제 0을 구분합니다. 같은 인스턴스의 기본 가격과 적용 가격을 분리합니다. 단일 관측을 다른 슬롯·캐릭터 또는 전투부대 자격에 일반화하지 않습니다.

실제 강화 UI에서 읽기 전용으로 수집 가능한 API, 호출 컨텍스트와 권한, 비밀값·전투 제한, 수집 실패 시 동작을 먼저 확인합니다. 현재 API 지원을 확정하지 않았습니다. 가방·은행 전체 관측을 강제하지 않습니다. 익명 fixture와 계약 합의 뒤 양쪽 구현과 교차 테스트를 배치합니다.

## TASK-006 진단 검토

ADDON-UPGRADE-001은 사용자가 NPC 창에서 선택한 한 장비의 다음 단계 API 응답을 읽는 진단이다. 아이템 ID/링크의 익명 일치만으로 장비 인스턴스, 장착 슬롯, 트랙을 확정할 수 없다. 현재·다음 rank와 레벨은 각각 PvE/PvP 여부 및 장비 스냅샷에 연결해 검증한다. 기본 가격과 서버 반환 적용 가격은 별도 상태로 기록하고, 적용 할인, 원시 watermarkSlot과 장착 슬롯, 캐릭터·전투부대 watermark 및 반지/장신구/무기 예외는 KR 실측 대조 대상으로 유지한다. 패치·빌드·시즌·관측 UTC·동일 인스턴스 및 골드/화폐별 수량을 함께 검증한 뒤 운영 계약을 논의한다. [진단 보고서](https://github.com/jeon950523/wow-gearpath-addon/blob/3e433b845c642c97815e1dce716b8d25c5dcd9c0/docs/reports/ADDON-UPGRADE-001-observations.md)
