TASK-005에서 성장 목표와 슬롯별 강화 분석, 다중 재화 최적화를 추가했습니다. 일반 강화·할인 실측이 없어 운영 소비안은 보류합니다. 최신 애드온 fixture와 웹 CLI/화면을 대조했습니다. [검수](reports/TASK-005-REPORT.md) · [실측 요청](contracts/UPGRADE-OBSERVATIONS-PROPOSAL.md)

현행 기준은 TASK-004입니다. 시즌 팩과 애드온 v0.3.0 수신을 검증했고, 새 화폐 세 종의 계약을 문서화했습니다. 다음은 애드온 담당자의 003B 게임 대조와 일반 강화·구렁·금고 표의 실측 검증입니다. [검수](reports/TASK-004-REPORT.md) · [계약](contracts/ADDON-003B-HANDOFF.md)

TASK-003A는 애드온 0.2.1 상세 필드와 개별 관측 시각을 지원합니다. 웹 교차 테스트가 계약 정본을 검증합니다. Actions는 수동 실행만 지원하며 Vercel은 main 자동 배포를 유지합니다. [검수](reports/TASK-003A-REPORT.md)

TASK-003은 [공통 계약](../contracts/CHANGELOG.md), 브라우저 가져오기·삭제, 장비 충돌 비교, 필드별 수집 상태, 솔플만 추천을 추가했습니다. [검수 결과](reports/TASK-003-REPORT.md)와 [로드맵](ROADMAP.md)을 참고하세요.

한국 리테일의 장착 장비와 재화 입력을 기반으로 솔플·구렁부터 경로를 제시합니다. Next.js, React, TypeScript, Node.js와 기존 CLI·진단 엔진을 사용합니다. 배포 프로바이더는 Vercel입니다.

검색, 최근 기록, 장비/평균, 교체 후보, 315 목표, 캐릭터 프로필, 재화·열쇠·쐐기·금고 입력, 조건별 경로와 샘플을 제공합니다. Blizzard API는 공개 캐릭터/장비, 서버 목록, 아이템 미디어 경로를 사용합니다. 강화 트랙과 보유 재고는 확인 가능한 경우만 적용합니다. 애드온은 스냅샷 입력 계약을 사용하도록 설계했으며 게임 내 애드온 제작은 남아 있습니다.

공식 공지에서 한밤 2시즌과 12.1.5 맹독석 조건 및 문장 상한 해제를 확인했습니다. 세부 보상표, 강화 비용과 할인, 제작 레벨은 추가 확인이 필요합니다. 수량과 기대 이득은 검증 이후 활성화합니다.

토큰 발급 중 요청을 공유하고 인스턴스 단위 TTL 캐시로 조회를 줄입니다. 캐시를 Vercel 인스턴스 간 공유하지 않습니다. 장비 스냅샷은 마지막 로그인 시각을 보수적으로 사용합니다. 트래픽 증가 시 분산 레이트 리밋이 필요합니다.

테스트, 운영 상태, 알려진 문제와 다음 순서는 [TASK-002 보고서](reports/TASK-002-REPORT.md)에 기록합니다.
